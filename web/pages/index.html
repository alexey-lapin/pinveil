    How it works

    • Your text, files, and file names are encrypted in this browser. The server stores only the ciphertext.
    • The key is the part of the link after #. Browsers never send it to the server.
    • Opening the message needs the link and the PIN. Too many wrong PINs delete it.
    • A message opens once, then the server deletes it. Unopened messages are deleted when they expire.
